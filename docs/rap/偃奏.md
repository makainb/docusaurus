# 偃奏

我喜欢 在这种昏暗的光线
让身边一切停顿只有音乐还有香烟
我喜欢 让灵感慢慢的浮现
让我的韵脚还有节奏感官随音乐浮现
我喜欢 记录着时间
让所有烦恼还有不该有的回忆遗忘在瞬间
我喜欢 聆听着音乐
让我的思想还有一切都能记住在这里面

我在这些天一直活着我自闭的空间
偶尔会有一些忏悔还有一些思念
眼看我的灵感就这样快要发霉
我在想 眼前这一切都是为了谁

这个夜很美 连月光也变得妩媚
看周围 七彩斑斓也不再乏味
谁是谁非，已经无所谓强求我不会
回忆都是累赘 请别再拖我的后腿

那些情情爱爱已经变得不再无奈
从明示到暗示不过最后一刀两断
欲擒故纵的暧昧游戏涮完了再涮
只是你应该注意主题玩家可能随时换

虽然生动的时间总是让人变得憔悴
但是遗忘的代价就是告诉自己别后悔
和往常一样 回头的路我必然不会
我尽力制造着机会 可是缘份始终天不给

这两天我不停的想词还有删词
这当中经历了什么 使我变成今天这样子
我用着简单的伴奏继续着我简单的节奏
是肆意还是放纵我都始终有恃无恐

我依旧都不想说我自己是多么的懵懂
在蜕变之后 我还是那样的潇洒依旧
我写了多少词 我只是自己不想发布
因为我清楚的明白那首八音已经谢幕

本来我想说那首歌应该叫做未完成
但是我不想只听预览版 我又不能
已经无力找人分工
只能随着回忆 在回收站里清空

一句各走各路 让我把一切冰封
确实曾经想过让自己休息不再弄
一阵莫名的痛 在胸口不停的燥动
我感觉受到了波动，原来我也如此被动

情绪起伏，于是我只能向前冲
我不擅长打退堂鼓 只能带上冲动
我开始不停的回避为了灵感不受波及
可是我丢了阵地 直到我如今拾起

其实我不想提起 只是我不想憋气
这该说的还是说出来 我这样才会满意
我不管他好不好听是心情也是作品
这就是我的兴趣，我不会为谁放弃
